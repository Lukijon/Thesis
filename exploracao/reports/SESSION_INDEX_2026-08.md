Result: genuinely different from debt-note text — the delisting correlation is the first in this whole project to survive clustering *without* controls (p=0.039), and the return correlation has the theoretically correct sign for the first time — but the portfolio-sort test (the rigorous method) still shows nothing significant for returns. Built the revision measure (`src/analysis/compute_eps_revisions.py`) and ran the same rigor progression across all four text sources (`src/analysis/run_h2_scenarios.py`, 56 tests total). **Clean, thorough null** — zero of 24 core similarity-vs-revision tests significant; the 4 secondary hits (~exactly the false-positive rate expected by chance across 56 tests) each fail on inspection, including a third instance of the project's now-familiar "significant naive, gone once clustered" trap. Also closed the historical/delisted EPS-coverage gap flagged in TODO.md (27/45 covered) and documented a real, still-open measurement caveat: the revision measure is built from a *rolling* consensus series, not a same-target-quarter series, because the current Bloomberg export can't support the latter.
9. **`control_specification_test.md`** — direct test of dropping "size" from the control set (per your question): doesn't flip any of 11 scenarios into significance by itself. But building the comparison surfaced a new number: management-report *returns*, with controls, clustered by company, p=0.03 — the most robust result the project had found, stress-tested hard (winsorizing, outlier removal, leave-one-company-out, rank correlation) and it held up every time. A dedicated portfolio-sort test conditioning on the same controls (`src/analysis/run_conditional_portfolio_sort.py`) moved in the right direction but stayed short of significance (best p=0.28) — a real tension between two methods, not yet resolved at that point.
10a. **`risk_factors_exploration.md`** (2026-09-03) — acted on the panel-model report's recommendation ("idea 2"): acquired Risk Factors (Formulário de Referência item 4.1), a genuinely new CVM filing type, not a data reuse. 923/978 company-years (94.4%), new pipeline (`src/acquisition/cvm_fre.py`) handling both modern (pre-isolated PDF) and legacy (opaque form-field code `"805"`, confirmed on two unrelated companies) filing formats. **H1 returns: null at every rigor stage, including fixed effects (p=0.76)** — even the theoretically strongest text source doesn't move H1. **But a genuinely new, well-supported finding on delisting**: a correctly-specified cross-sectional test (one row per company, n=110 — avoiding the repeated-observations problem by construction instead of correcting for it) shows p=0.030 (OLS) / p=0.039 (logit), survives leave-one-out and a median-instead-of-mean check. Best-supported result in the project so far, but it's about delisting/text-validity, not the core return-predictability question, which stays null.
10. **`panel_model_results.md`** — resolved that tension. Built the company+year fixed-effects panel model recommended throughout this session (`src/analysis/run_panel_models.py`, `linearmodels.PanelOLS`, clustered by company) across all 8 scenarios where it's statistically valid (H1 returns and H2 revisions x 4 text sources). **The mgmt-report return result does not survive it** (p=0.03 pooled -> p=0.48 with fixed effects) — consistent with the pooled result having been a stable cross-company pattern (some firms are just steady narrators *and* perform differently for unrelated reasons) rather than a real within-company signal. Every other H1/H2 scenario was already null and stays null. Also documents, by deliberately running it and showing the output, why company fixed effects are mathematically inapplicable to the delisting/survivorship check (a time-invariant-per-company outcome) — a real trap (machine-precision-zero coefficient paired with a "significant" p=0.0006) caught before it could be reported at face value. **This is the most rigorous test available in this project's toolkit, and it closes out H1 and H2 as null across every text source, frequency, and method tried.**
